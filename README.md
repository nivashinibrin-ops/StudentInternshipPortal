# Student Internship Portal

## Description
A React-based web application that allows students to explore available internships and view their applications through a simple and user-friendly interface.

## Features
- Attractive home page with a welcome message.
- Displays available internships.
- Home navigation.
- My Applications section.
- Simple and user-friendly design.

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Concepts Covered
- React Components
- JSX
- JavaScript Expressions
- CSS Styling
- Navigation and UI Design

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal.
